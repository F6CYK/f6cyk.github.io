# Fonctionnement du composant flipbook

Le composant construit le chemin du PDF à partir de :

    {{ page.asset_path }}/{{ include.file }}

Conséquence :

- transmettre uniquement le nom du fichier via `file="..."` ;
- ne jamais transmettre un chemin complet.

# Évolution du menu

Constat :

Le fichier `_includes/menu.html` ne doit pas devenir le point de maintenance principal.

Décision validée :

Créer un fichier :

    _data/materiel.yml

Le menu « Matériel » sera généré par :

    {% include recursive-menu.html noeuds=site.data.materiel %}

Le composant `recursive-menu.html` sera réutilisé comme pour `documentation.yml`.

---

# Choix d'architecture

- privilégier les fichiers YAML ;
- conserver les composants génériques ;
- éviter le HTML codé en dur ;
- une modification à la fois ;
- validation avant poursuite.
